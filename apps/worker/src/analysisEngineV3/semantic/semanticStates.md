# Semantic States

The Semantic Interpretation Layer advances through states.

These states are descriptive, not executable.

## State 1. Unresolved

The sentence has not yet been semantically interpreted.

## State 2. Evidence Located

A literal candidate span exists and is ready for interpretation.

## State 3. Speaker Hypothesized

The likely speaker has been identified or tentatively identified.

## State 4. Listener Hypothesized

The likely listener has been identified or tentatively identified.

## State 5. Target Hypothesized

The likely target has been identified or tentatively identified.

## State 6. Narrative Mode Identified

The system has determined whether the text is dialogue, narration, description, documentary, satire, and so on.

## State 7. Intent Interpreted

The system has determined the likely narrative intent.

## State 8. Context Integrated

Story Memory, Scene Memory, and neighboring text have been integrated into the semantic reading.

## State 9. Risk Context Assigned

The sentence has a semantic risk context.

## State 10. Semantically Stable

The layer has reached a confident semantic interpretation.

## State 11. Ambiguous

The layer cannot reliably determine meaning without over-inference.

## State 12. Ready for Legal Evaluation

The semantic meaning is complete enough to pass to the legal layer.

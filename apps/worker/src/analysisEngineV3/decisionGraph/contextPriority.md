# Context Priority

Context priority defines which interpretive sources are consulted first.

## Priority Order

1. Chunk
2. Local Sentences
3. Scene Memory
4. Story Memory
5. Glossary

## Rules

- The chunk is the primary context.
- Local sentences are the strongest contextual neighbor to the candidate span.
- Scene Memory helps link the chunk to the surrounding dramatic beat.
- Story Memory helps link the chunk to the broader narrative.
- Glossary helps interpret lexical meaning.

## Consequences

- Context may explain the candidate evidence.
- Context may not replace the candidate evidence.
- Higher-priority context always overrides a weaker interpretive reading from lower-priority context.

# Evidence Priority

Evidence priority defines which sources are allowed to support classification and in what order.

## Priority Order

1. Literal Chunk
2. Dialogue
3. Narration
4. Scene Description
5. Story Memory
6. Glossary

## Rules

- Literal chunk text is the highest-priority evidence source.
- Dialogue, narration, and scene description are still part of the chunk and remain admissible.
- Story Memory may help interpret the chunk, but it is not evidence by itself.
- Glossary is knowledge support, not evidence.

## Consequences

- If a statement is present in the literal chunk, it can be evaluated.
- If it is only implied by memory, it is not evidence.
- If the evidence is only inferential and not textual, it must not produce a finding.

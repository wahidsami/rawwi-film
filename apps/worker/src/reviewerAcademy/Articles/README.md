# Articles

Each GCAM article lives in exactly one markdown knowledge document in this folder.

Canonical structure:
- one file per article
- one article id per file
- article-specific law only
- shared reviewer brain in `../Universal/11_Universal_Review_Protocol.md`

The article files are the canonical knowledge source for future GCAM reviewer reasoning.
The reviewer packs in `../Reviewers/` are legacy compatibility folders and should not duplicate article law.
